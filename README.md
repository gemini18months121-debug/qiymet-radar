## 📱 1. Telefonda APK Kimi İstifadə (Mobil Tətbiq - PWA)
Sayt **PWA (Progressive Web App)** standartını dəstəkləyir:
1. Telefonunuzun brauzerində (Chrome və ya Safari) tətbiqin linkini açın.
2. Brauzerin menyusundan **"Ana ekrana əlavə et" (Add to Home Screen)** və ya ekrandakı **"Quraşdır"** düyməsinə basın.
3. Telefonunuzun ana səhifəsinə eynilə APK proqram kimi tətbiq ikonası düşəcək.
4. Açanda brauzer ünvan zolağı olmadan, təmiz **tam ekran mobil proqram (APK)** kimi işləyir.

---

## 🤖 2. Telegram Botu ilə İstifadə
1. Telegram-da **@BotFather** botuna daxil olub `/newbot` yazın və botunuza ad verin.
2. BotFather sizə verilən `TOKEN`-i kopyalayın.
3. `.env` faylına daxil olub yapışdırın:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:AAH...
   ```
4. Artıq Telegram-dan istənilən məhsulu (məs: `Capcut`, `Windows 11`, `Canva`) göndərdikdə 2 saniyəyə ən ucuz qiyməti alacaqsınız.
